# Employee Salary Analysis Using Python

## 📌 Project Overview

The **Employee Salary Analysis** project is a Python-based program developed as part of my internship learning journey at **Veda Technology**. It analyzes employee salary data and calculates the total salary, average salary, highest salary, and lowest salary using Python's built-in functions.

## 🎯 Objectives

- Store employee salary values in a Python list.
- Calculate the total salary of all employees.
- Find the average employee salary.
- Identify the highest and lowest salaries.
- Display the results in a clear and readable format.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Platform:** Google Colab / Jupyter Notebook
- **Version Control:** GitHub

## 💻 Python Concepts Used

- Python lists
- `sum()` — calculates the total salary
- `len()` — counts the number of employees
- `max()` — finds the highest salary
- `min()` — finds the lowest salary
- `round()` — rounds the average salary
- Variables and formatted print statements (f-strings)

## 📊 Sample Data

The program uses a list of 11 sample employee salaries:

salaries = [
